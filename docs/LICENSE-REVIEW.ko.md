# 라이선스 검토 및 공개 범위 — 2026-10-10

기기 소스·설정 21개는 파일별 출처와 라이선스 근거가 부족해 이번 공개에서 제외했습니다. 라이선스 표기가 없다는 사실만으로 위반이라고 판단한 것은 아닙니다. 직접 작성한 파일과 외부 도입 파일을 구분한 다음 공개 범위를 정하겠습니다.

해당 파일이 담긴 이전 비공개 로컬 커밋도 공개 브랜치의 조상으로 포함하지 않습니다. 기기별 백업, 인증키, vendor 바이너리 및 ROM 이미지는 공개하지 않습니다.

이 개발 작업 트리는 Acer와 공유했습니다. 2026-10-11 현재 11개 프로젝트·23개 파일의 패치를 이 저장소에도 원본 고지사항·기준 커밋·파일 해시와 함께 공개합니다. Apache 대상 22개 파일과 Skia BSD-3-Clause 파일 1개의 원본 헤더를 확인했고, 해당 라이선스 전문을 `LICENSES/`에 보존했습니다. 기기별로 분리된 완성된 패치 세트가 아니며 전체 ROM의 재현성이나 동작을 보장하지 않습니다. 현재 실기기 소스를 변경하지 않는 원본 Git index 검사는 통과했습니다.

kernel/boot 배포에는 실제 바이너리에 대응하는 커널 소스와 설정·빌드 절차를 준비해야 합니다. 독점 GPU·코덱·Wi-Fi 파일도 별도 검토가 필요합니다. 원본 커널을 재사용한다고 이 검토가 생략되는 것은 아닙니다.

법적 무위험을 보증하는 문서는 아닙니다. 검토를 완료하지 못한 파일을 공개에서 제외해 범위를 제한한 상태입니다.

2026-10-11 소유자 입력 경로를 추가했습니다. 공개 색인에는 원본과 비교한 제조사 입력·오디오 설정·원본 Wi-Fi 모듈 25개의 파일명/크기/해시만 있습니다. 바이너리와 원본 설정 내용은 포함하지 않습니다. 개인 MAC 주소가 포함된 `nvram_ap6212.txt`는 공개 색인에서 내용과 해시를 모두 제외했습니다. 추출 도구의 프로젝트 코드는 Apache-2.0이지만, 이 라이선스는 추출된 제조사 파일이나 GPL 커널 모듈에 적용되지 않습니다. 원본 Wi-Fi 모듈이 존재한다는 사실은 대응 커널 소스 제공 의무를 충족했다는 뜻이 아니므로 해당 바이너리 배포는 계속 보류합니다.

## 이후 공개 소스와 비공개 이미지의 구분

위 21개는 초기 원본 작업 스냅샷의 제외 범위입니다. 이후 별도로 검토한 프로젝트 작성 기기 설정 16개와 출처·원본 고지사항을 보존한 HWC/그라록 소스 32개는 공개했습니다. 해당 소스의 색인은 `source/dangol-device-provenance.json`과 `source/dangol-hwc-provenance.json`입니다. 이 공개는 원본 스냅샷 전체나 제조사 바이너리의 배포 승인을 뜻하지 않습니다.

2026-10-11 기존 최종 이미지에서 개인 보정 파일을 제외한 새 비공개 후보를 만들었습니다. 제한된 인증정보 검사와 파일시스템 검사는 통과했지만, 이후 설치 경로 대조에서 제조사 입력 색인의 **25개 모두**가 기존 지문과 일치했습니다. 보정값을 없앴다고 그 파일의 재배포 권한이 생긴 것은 아닙니다. 해당 입력의 `redistribution_approved=false` 정책은 유지합니다. 이 대조는 ROM의 모든 파일에 대한 완전한 라이선스 검사가 아닙니다.

현재 후보를 공개 Release로 업로드하지 않습니다. 재배포 조건을 확인하거나, 해당 파일을 제외한 기반 이미지와 소유자 측 완전한 재구성 절차를 제공해야 합니다. 드라이버가 빠진 기반 이미지를 즉시 부팅 가능한 최종 ROM으로 표시해서는 안 됩니다. 원본 커널과 모듈의 정확한 대응 소스 문제도 별도로 남아 있습니다.

[AOSP 공식 라이선스 설명](https://source.android.com/docs/setup/contribute/licenses)에서도 대부분의 Apache-2.0 코드와 Linux GPLv2 등의 예외를 구분합니다. 추출·조합 도구의 프로젝트 라이선스, 공개 저장소 URL 또는 인증정보 검사 통과만으로 개별 바이너리의 의무를 충족했다고 판단하지 않습니다.
