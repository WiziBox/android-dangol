# 공개 전 체크리스트

목표는 배포 준비 문서가 아니라, 다른 PC에서도 빌드·다운로드·설치·복구할 수 있는 최종 배포본입니다. 현재 그 전체 경로는 미완성이고 ROM 공개는 보류되어 있습니다. 아래 필수 조건의 근거를 확보한 뒤 최종본으로 표시합니다.

- [x] 공개 HTTPS 원격과 709개 커밋으로 고정한 upstream manifest 제공
- [x] 출처·기준 커밋·해시·원본 고지를 포함한 11개 프로젝트 패치 제공
- [x] 빈 WSL 경로에서 upstream 초기화 및 실제 기준 커밋 패치 적용 가능 여부 확인
- [x] Windows/Linux에서 기존 도구 테스트 26개 통과
- [x] 빌드 설정이 참조하는 Nexell HWC 소스 27개와 gralloc 헤더 5개의 원본 커밋·라이선스·파일 해시 보존
- [ ] 기존 개발 경로나 out에 의존하지 않는 전체 클린 빌드 완료
- [ ] 검토된 Release 이미지·SHA256·소스/도구 리비전 제공
- [ ] 저장소의 설치·복구 절차를 실제 배포 이미지로 끝까지 수행하고 결과 기록

- [ ] 최종 device tree와 실제 동작한 수정의 출처·커밋 기록
- [ ] 프레임워크 및 HAL 패치의 원본 버전과 라이선스 보존
- [ ] 기존 커널 바이너리의 대응 소스·설정·변경 내역 확인
- [ ] 사용자 데이터, 장치 일련번호, MAC 주소, SSID 및 로그 제거
- [ ] ADB 개인키·공개키·승인 목록 및 개인 서명키 제거
- [ ] 루트·SELinux·USB/네트워크 ADB 정책을 배포 문서에 명시
- [ ] 독점 GPU·코덱·Wi-Fi 바이너리의 재배포 조건 확인
- [ ] 배포용 이미지와 실제 후속 수정의 일치 확인
- [ ] 크기가 늘어난 boot를 처리하는 부트로더 절차 문서화
- [ ] 다른 장치의 U-Boot 환경을 덮어쓰지 않는 설치 절차 마련
- [ ] 부팅·화면·터치·영상·소리·Wi-Fi·절전 회귀 결과 기록
- [ ] 복구 방법과 SHA256 제공

완료되지 않은 항목은 Release 설명에서 명확히 알립니다. 검증되지 않은 후보를 stable로 표시하지 않습니다.
